## The Crisis Nobody Is Solving

**70% of published scientific findings cannot be replicated.**

That number is not a typo. It is the reproducibility crisis — and it is quietly costing the world billions of dollars in wasted follow-up research, corrupting medical decisions, and eroding public trust in science itself.

The problem is not that scientists are dishonest. The problem is that **peer review is broken by design.**

Reviewers are overworked. They check one paper at a time. They cannot cross-reference figures across 50 pages. They cannot detect when p-values have been massaged. They cannot run forensic analysis on every image in a manuscript.

**A machine can. That is what SciPeerAI is.**

## What It Does — 24 Modules

<table>
<tr>
<td width="50%">

### ✅ Module 01 — Statistical Audit Engine
Detects p-hacking by identifying suspicious clusters near the 0.05 threshold. Flags underpowered sample sizes and suspiciously round numbers.

### ✅ Module 02 — Methodology Logic Checker
Rule-based detection with negation awareness. Detects causation claims without RCT, missing control groups, timeframe mismatches.

### ✅ Module 03 — Citation Integrity Analyzer
Detects self-citation abuse, unsupported broad claims, low citation density. Supports plain Author Year format.

### ✅ Module 04 — Reproducibility Scanner
Scores paper across 8 dimensions: code, data, software versions, preregistration, ethics, IRB approval.

### ✅ Module 05 — Novelty Scorer
Structural language signals combined with live Semantic Scholar search. Detects incremental vs genuinely novel work.

### ✅ Module 06 — GRIM Test
Detects mathematically impossible means. If n=15 and reported mean is 3.47, the math proves the data cannot be real.

### ✅ Module 07 — SPRITE Test
Detects impossible score distributions including near-zero SD anomalies. Upgraded with minimum SD bounds check.

### ✅ Module 08 — Granularity Analyzer
Applies Benford's Law to numeric data. Real measurements follow predictable digit distributions — fabricated data does not.

### ✅ Module 09 — P-Curve Analyzer
Detects publication bias by analyzing the shape of p-value distributions. Genuine effects produce right-skewed p-curves.

### ✅ Module 10 — Effect Size Validator
Validates Cohen's d, correlation coefficients, and odds ratios against sample sizes. Catches inflated effects and underpowered claims.

### ✅ Module 11 — Retraction Checker
Three-layer DOI detection — prefix, bare pattern, and paper identity signals. Catches Wakefield 1998 and all known retracted papers automatically.

### ✅ Module 12 — Citation Cartel Detector
Graph-based network analysis. Detects coordinated mutual citation rings. Supports plain Author Year format.

</td>
<td width="50%">

### ✅ Module 13 — LLM Paper Detector
Detects AI-generated papers using burstiness scoring, type-token ratio, sentence uniformity, and LLM phrase detection.

### ✅ Module 14 — Figure Forensics
Extracts every image from a PDF and runs perceptual hashing for duplicate detection. PDF-only module.

### ✅ Module 15 — Fraud Fingerprinting
Writing DNA inconsistency detection across paper sections. Catches ghost-writing and multi-author style mixing.

### ✅ Module 16 — Temporal Anomaly Detector
Four-layer year extraction — detects future citations, data collection paradoxes, and impossible timelines. Supports plain Author Year format.

### ✅ Module 17 — Citation DNA Analyzer
Herfindahl-Hirschman Index on author, journal, decade, and geographic concentration. Identifies citation echo chambers.

### ✅ Module 18 — Data Fingerprint Analyzer
Terminal digit bias, round number clustering, and impossible statistical pairs. Benford-level fabrication detection.

### ✅ Module 19 — Peer Review Score
Detects rapid acceptance (< 7 days), special issue bypass, predatory journal signals, and conflict of interest gaps.

### ✅ Module 20 — AI-Human Spectrum
GPT-4, Claude, and Gemini signature phrase detection with model attribution confidence scoring.

### ✅ Module 21 — Replication Predictor (ML Ensemble)
LightGBM + XGBoost + RF + LR trained on SciPeerBench v2.0 (91,779 papers). Ensemble AUC: 0.895. Predicts replication probability from 37 text-based features.

### ✅ Module 22 — Research Genealogy Engine
Citation ancestry, lineage concentration, retracted ancestor detection. Identifies closed citation rings.

### ✅ Module 23 — Field Saturation Detector
Topic overcrowding, novelty claim inflation, contribution vagueness scoring.

### ✅ Module 24 — Institutional Conflict Score
Undisclosed COI detection, industry funding bias, self-serving citation patterns, overstated conclusions.

</td>

## Quick Start

```bash
git clone https://github.com/Abu-Sameer-66/SciPeerAI.git
cd SciPeerAI
conda create -n scipeerai python=3.10 -y
conda activate scipeerai
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

Local API → `http://localhost:8000`
Live API  → `https://abu-sameer-66-scipeerai-api.hf.space`
Live UI   → `https://scipeerai-ui.vercel.app`

## API Usage

```bash
# statistical fraud detection
curl -X POST "https://abu-sameer-66-scipeerai-api.hf.space/api/v1/analyze/statistics" \
  -H "Content-Type: application/json" \
  -d '{"text": "n=12 participants. p=0.048. Secondary also p=0.049."}'

# GRIM test
curl -X POST "https://abu-sameer-66-scipeerai-api.hf.space/api/v1/analyze/grim" \
  -H "Content-Type: application/json" \
  -d '{"text": "n=15, mean=3.47, SD=1.2"}'

# retraction check
curl -X POST "https://abu-sameer-66-scipeerai-api.hf.space/api/v1/analyze/retraction" \
  -H "Content-Type: application/json" \
  -d '{"text": "Wakefield et al. doi:10.1016/S0140-6736(97)11096-0"}'

# ML replication prediction
curl -X POST "https://abu-sameer-66-scipeerai-api.hf.space/api/v1/analyze/replication" \
  -H "Content-Type: application/json" \
  -d '{"text": "paste paper text here"}'

# full 24-module PDF analysis
curl -X POST "https://abu-sameer-66-scipeerai-api.hf.space/api/v1/analyze/full-pdf" \
  -F "file=@paper.pdf"
```
